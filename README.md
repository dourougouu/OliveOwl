# OliveOwl
<img src="assets/OliveOwl.png" alt="Olive Owl Logo" width="150">

### **An Olive Mill Management System**
---

## Overview

Here I will develop a software application for managing the basic operations of an olive mill, including producer records, olive deliveries, delivery history and printable documents.

> The initial version will be a prototype. Requirements will be refined after discussions with the business owner.

---

## Dependencies

**Database**
- PostgreSQL: 18.6

**Backend**
- Python: 3.14.2
- FastAPI: Backend API Framework
- Uvicorn: ASGI server for running the FastAPI application
- Psycopg 3: PostgreSQL database adapter
- python-dotenv: Environment variable configuration

**Development Tools**
- VScode
- Git & GitHub
- Python Virtual Environment (venv)
